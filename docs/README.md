# Project Documentation

This directory contains official engineering documentation, user manuals, milestone deliverables, and validation reports produced for the Deca compiler project at Grenoble INP - Ensimag.

## Documentation Index

### 1. User & Technical Manuals
- **[Manuel Utilisateur (PDF)](file:///home/ensimag/GL_FINAL/gl10/docs/Manuel_Utilisateur.pdf)**: Complete compiler user guide including command-line flags (`-p`, `-v`, `-d`, `-P`, `-r X`), compilation phases, error diagnostics, and specification of the **TAB Extension** (matrices and 2D arrays).
- **[Documentation de Validation (PDF)](file:///home/ensimag/GL_FINAL/gl10/docs/validation.pdf)**: Comprehensive test strategy and verification document, including test suites for Phase A (lexer/parser), Phase B (contextual checks), Phase C (IMA code generation), performance profiling, and test coverage metrics.

### 2. Milestone Deliverables (Suivis)
- **`suivi1/`**: Initial sprint review, architecture planning, charter auto-evaluations, and preliminary error handling strategy.
- **`suivi2/`**: Mid-project progress defense, extension specification (`Ext_TAB.pdf`), and risk management report (`Gestion_des_risques_rendu.pdf`).
- **`suivi3/`**: Final sprint tracking, updated risk mitigation (`Gestion_des_risques_rendu(2.0).pdf`), and final project presentation slides.

### 3. Project Management
- **`planning/`**: Project tracking, Gantt charts, and resource allocation (`Planning.planner`, `planning.pdf`, `Realisation.pdf`).
