# Security Policy

## Supported Versions

The Deca compiler project maintains and supports the latest release branch:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability or critical issue within the Deca compiler (e.g., unintended code execution, compiler memory safety, stack overflow in AST recursion), please report it responsibly:

1. **Do not** disclose the vulnerability publicly in an open GitHub issue.
2. Send an email to the project maintainer:
   - **Marwane Hajjy**: `marwane.hajjy@grenoble-inp.org`
3. Please include:
   - A clear description of the vulnerability.
   - Minimal reproducible Deca source snippet.
   - Operating system and Java runtime environment details.
   - Any proposed remediation or patches.

You will receive an initial response within 48 hours acknowledging receipt of your report.
